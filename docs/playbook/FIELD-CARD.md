# Field card — what to paste when
| Situation | Do this |
|---|---|
| Problem released | Prompt 01 -> Captain chat (get MVP + acceptance tests) |
| Repo empty | Prompt 02 -> Codex/Claude Code on this folder |
| Need UI | Prompt 03 Designer -> Prompt 04 frontend |
| Need backend/AI | Prompt 05 (follows api-contract.md) |
| Feature coded | Prompt 06 independent tester (PASS/FAIL evidence) |
| Combine work | Prompt 07 review -> Prompt 08 integrate -> build + smoke test |
| Broken | Prompt 09 with exact error + steps |
| Demo prep | Prompt 10 with verified features + rubric |
| Every task end | Prompt 11 handoff |
Rule of five: understand judges, smallest complete feature, test what you have, keep main working, practice demo.
